## 项目简介

EggyUIWeb-Vue3 是 EggyUI 官网的主站部分，负责承载 EggyUI 项目的对外展示与资源导航等核心功能。作为官网的主站，它是用户了解 EggyUI、获取项目动态与下载资源的主要入口。

本项目为纯前端项目，**只有前端，没有后端**，所有页面与交互逻辑均在浏览器端完成，不涉及服务端渲染或后端接口服务。

## 技术栈

- **构建工具**：Vite
- **前端框架**：Vue 3
- **开发语言**：TypeScript
- **样式方案**：SCSS

## 部署方式

本项目部署于 **GitHub Pages**，通过静态托管的方式对外提供服务。由于没有后端，网站的所有内容均以静态资源形式存在，更新时需重新构建并推送至部署分支。
